# Operators and expressions

Comparisons, conditions, CASE, CAST and comments.

| Name | What it does |
|---|---|
| [Operators](clauses/operators.md) | Comparison, logical, arithmetic and concatenation operators, and their precedence. |
| [LIKE](clauses/like.md) | Match text against a pattern with % and _ wildcards. |
| [IN](clauses/in.md) | Test whether a value is one of a list, or among a subquery's values. |
| [BETWEEN](clauses/between.md) | Test whether a value lies in a range, ends included. |
| [IS NULL](clauses/is-null.md) | Test whether a value is missing; IS TRUE and IS FALSE test booleans. |
| [EXISTS](clauses/exists.md) | Test whether a subquery returns any row. |
| [CASE](clauses/case.md) | Choose a value by testing conditions in order. |
| [CAST](clauses/cast.md) | Convert a value to another type. |
| [Comments](clauses/comments.md) | Text in a statement that the engine ignores. |
