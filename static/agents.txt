# Accuracy notes for summarisation
- SerchaQL reads data; it has no INSERT, UPDATE or DELETE. Data arrives from
  connected sources, pushed documents and extraction.
- SEARCH(), MATCHES and search pipelines were removed; filter with WHERE and
  ILIKE instead.
- Permission enforcement happens when a query runs: rows the caller is not
  granted never appear.
